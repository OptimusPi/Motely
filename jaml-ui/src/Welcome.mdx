# jaml-ui

JAML is Jimbo's Ante Markup Language — a DSL for Balatro seed filters. This package is its
video-game UI, shipped as an MCP app first: it renders inside a host iframe we do not control.
That constraint is the reason for every rule below.

## The design rules

These are enforced by a pre-write hook that blocks violating edits before they land.
The rule is the requirement; if one blocks you, your approach is the thing that changes.

1. **Grid or absolute positioning only.** MCP hosts size flex content differently per host,
   so the same markup would reflow per embed. Grid is deterministic: `place-items: center`
   to center, `grid-auto-flow: column` for a row. `gap` is fine inside a grid.
2. **Interactive elements come from `src/ui/`.** Compose a `Jimbo*` primitive. If the
   primitive you need is missing, add it to `src/ui/` with a story.
3. **Icons come from react-icons** (`react-icons/fi` preferred).
4. **Normal case text.** Acronyms (JAML, JSON, MCP) are fine.
5. **Normal weight text.**
6. **Styling lives in `.j-*` classes and `--j-*` tokens.** The one inline-style shape
   consumers may use is CSS custom-property assignment, e.g. `style={{ "--j-card-width": w }}`.
7. **`JimboColorOption` is for canvas / R3F / SVG only** — surfaces that cannot read CSS
   variables. In JSX, use the matching `--j-*` custom property.
8. **Reusable UI is a primitive with a story**, not a helper function inside a screen.

## Where things live

- **Foundations** — the `--j-*` tokens made visible: colors, type scale, spacing, the shader.
- **Primitives** — every `Jimbo*` control, grouped by role. Sidebar name matches the import name.
- **Cards & Sprites** — the sprite-sheet surfaces (`DeckSprite`, `GameCard`, `JimboSprite`).
- **Wire Format** — json-render stories proving a JSON spec renders without React in the loop.
- **Screens** — the composed app surfaces (JAML IDE, Jamlyzer, Ante Map).

## Adding a primitive

Create `src/ui/JimboThing.tsx` plus `JimboThing.stories.tsx` titled
`Primitives/<Role>/JimboThing`, style it with `.j-*` classes in `jimbo.css` using existing
tokens, and keep the sizes on the pixel grids: m6x11plus reads best at 18/36/54,
m6x11 at 16/32/48.

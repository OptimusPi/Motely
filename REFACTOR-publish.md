# Refactor: Simplify npm publish to match Bootsharp docs

## The problem
6 overlapping scripts (build.mjs, publish.ps1, sync-version.mjs, stage-wasm.mjs, sync-wasm.mjs, package.json scripts) doing what `dotnet publish` already does by itself.

## What Bootsharp actually does
`dotnet publish` outputs a ready-to-publish npm package to `bin/bootsharp/`:
- `index.mjs` (ES module with embedded binaries)
- `types/` (generated TypeScript declarations)
- `package.json` (generated by Bootsharp)

Source: https://bootsharp.com/guide/getting-started

## What the workflow SHOULD be

### motely-wasm
```
dotnet publish Motely.Orchestration -c Release -p:WasmBuild=true
npm publish ./Motely.Orchestration/bin/bootsharp
```

Two commands. That's it.

### motely-node
Node native addon (not Bootsharp) — still needs staging. Keep a minimal script for this one only.

## Version bumping
Use `npm version patch` on the generated `bin/bootsharp/package.json` before publish, or set version via .csproj `<Version>` property which Bootsharp reads.

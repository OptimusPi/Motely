# DATA FORMATS
Format-JAML: YAML-based filter configuration
Format-JSON: JSON filter configuration (also supported)
Format-Results-JSON: Array of objects: [{ seed: string, score: number, tallies: number[] }]
  - seed: Balatro seed string (e.g., "ALEEB", "12345678")
  - score: Total score (sum of all should clause scores)
  - tallies: Array of integers, one per "should" clause in JAML config
    - Each tally value corresponds to a "should" clause (in order)
    - Column names come from "label" field of each "should" clause (or auto-generated)
Format-Results-CSV: Comma-separated: seed,score,tally1,tally2,tally3,...
  - First column: seed
  - Second column: score
  - Remaining columns: One per "should" clause (tally values)
  - Column headers: ["seed", "score", <label1>, <label2>,...]

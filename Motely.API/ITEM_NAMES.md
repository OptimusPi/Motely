## Notes

- **Joker Names:** Use exact enum names (e.g., `LuckyCat`, not "Lucky Cat")
- **Tarot Names:** Use exact enum names (e.g., `TheFool`, not "The Fool")
- **Voucher Names:** Use exact enum names (e.g., `OverstockPlus`, not "Overstock Plus")
- **Case Sensitive:** All names are case-sensitive in JAML filters
- **Display Names:** For user-facing text, convert PascalCase to "Display Name" (e.g., `LuckyCat` → "Lucky Cat")

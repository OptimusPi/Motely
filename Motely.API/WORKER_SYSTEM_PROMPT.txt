This file contains the system prompt that should be hardcoded in your Cloudflare Worker.

To update your Worker:
1. Copy the output from GetSystemPrompt() method in McpServer.cs
2. Paste it as a constant in your Worker code
3. Deploy the updated Worker

The system prompt is generated dynamically in the backend, but for security reasons,
it should be hardcoded in the Worker (users should NOT be able to provide system prompts).

Run the backend and check logs to see the full system prompt, or look at GetSystemPrompt() method.
